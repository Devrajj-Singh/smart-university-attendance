EXECUTION FLOW
================================================================================

Application Startup Flow:

1. main() called
   ↓
2. initializeDatabase()
   ├─ Establish SQLite connection
   └─ Verify connection
   ↓
3. initializeServices()
   ├─ Create AttendanceService
   ├─ Create AuthenticationService
   ├─ Create SyncService
   └─ Create DashboardService
   ↓
4. loadDummyData()
   ├─ Load sample timetable
   ├─ Load sample students
   └─ Load sample faculty
   ↓
5. showLoginInterface()
   ├─ Display login instructions
   ├─ Prompt for credentials
   ├─ Validate with LoginService
   └─ Open FacultyDashboard
   ↓
6. FacultyDashboard.start()
   ├─ Display menu loop
   ├─ Get user input
   ├─ Route to menu option
   └─ Repeat until logout
   ↓
7. shutdown()
   ├─ Close database connection
   └─ Close Scanner resource
